# ドッヂボールタイマー 公開手順

このフォルダをそのままWebに置くと、URLで配れるアプリになります。

## 中身
- index.html … タイマー本体
- manifest.webmanifest … ホーム画面に追加したときの名前・アイコン・全画面起動の設定
- sw.js … 一度開いたあと、電波がなくても動くようにする設定
- icons/ … アイコン

## 公開する（どれか1つ）

### A. Netlify Drop（いちばん簡単）
1. パソコンのブラウザで https://app.netlify.com/drop を開く
2. このフォルダ（dodgeball-timer）をそのままドラッグ&ドロップする
3. 表示されたURLがタイマーのアドレスです

### B. GitHub Pages
1. GitHubで新しいリポジトリを作り、このフォルダの中身を全部アップロードする
2. リポジトリの Settings → Pages で、公開するブランチ（main）を選んで保存する
3. 数分後に表示されるURLがタイマーのアドレスです

## LINEで配る
1. 発行されたURLをLINEのトークやグループに貼る
2. 受け取った人がURLをタップすると、LINE内のブラウザで開き、そのまま使えます
3. 試合で使うときは、右上のメニューから「他のブラウザで開く」（Chromeなど）を選ぶと安定します
4. Chromeで開いたら、右上のメニュー（︙）→「ホーム画面に追加」（または「アプリをインストール」）で、アイコンから全画面で起動できます

## 更新するとき
index.html を直したら、sw.js の先頭付近にある `const VERSION = 'v1';` の数字を上げて、もう一度アップロードしてください。上げないと、使っている人の端末に古い版が残ることがあります。

## 注意
- HTTPS のURLで公開してください（NetlifyもGitHub Pagesも自動でHTTPSになります）。ファイルを直接開くだけだと、オフライン設定とホーム画面追加は働きません。
- 文字のフォントはGoogle Fontsから読み込みます。一度開けばオフラインでも表示されます。読み込めない場合は端末の標準フォントで表示されます。
